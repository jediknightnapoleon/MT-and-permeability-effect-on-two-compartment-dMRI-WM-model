# MT-and-permeability-effect-on-two-compartment-dMRI-WM-model
Repo for code that reproduces the results and analysis in MRM paper Investigating the sensitivity of diffusion MRI measurements to magnetization transfer and permeability via Monte-Carlo simulations <add link>.\
## Pre-requisites
1. Install Julia from the [official website](https://julialang.org/downloads/).
2. Install the MCMRSimulator following its [documentation](https://open.win.ox.ac.uk/pages/ndcn0236/mcmrsimulator.jl/dev/installation/).
